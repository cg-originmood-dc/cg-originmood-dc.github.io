# 伊利斯礦山路線圖規劃

## 目標

新增獨立的「伊利斯礦山」地圖頁，服務三種需求：

1. 從魯米那斯村穿越礦山，前往米諾基亞村並開傳送點。
2. 前往指定礦點採集，不必重新判讀整張大坑道。
3. 前往爆岩一級點或初心新增的 S 階礦點。

預定頁面：`/地圖座標/庫魯克斯島/伊利斯礦山/`

## 地圖拓樸

礦山是三張固定地圖，結構為 F1 → F2 → F1：

`庫魯克斯島（魯米那斯側 315,822） → 伊利斯礦山 F1（魯米側） → 大坑道 F2 → 伊利斯礦山 F1（米諾側） → 庫魯克斯島（381,804）`

外部攻略目前可交叉確認的轉點：

| 區段 | 已知座標 | 狀態 |
| --- | --- | --- |
| 庫魯克斯島進礦山 | `(315,822)` | 已有多個來源一致 |
| 魯米側 F1 下大坑道 | `(41,7)` | 需以初心服實測確認落點與地圖編號 |
| 大坑道往米諾側 | 舊攻略記為 `(118,12)` | 初心服可能不同，需實測 |
| 米諾側 F1 出礦山 | `(85,93)` | 需以初心服實測確認 |
| 回到庫魯克斯島 | `(381,804)` | 已有多個來源一致 |

## 圖面拆分

### 1. 庫魯克斯島區域總覽

只標示與礦山交通有關的節點：

- 哥拉爾東門 `(283,437)`
- 橋樑關卡 `(477,526)`
- 魯米那斯村 `(321,883)`
- 魯米側礦山入口 `(315,822)`
- 米諾側礦山出口 `(381,804)`
- 米諾基亞村西門約 `(430,823)`

這張圖回答「礦山在哪裡」；不放礦點，避免與洞內路線混在一起。

### 2. 魯米那斯側 F1

- 青藍色主線：庫魯克斯島入口 → `(41,7)` 下大坑道。
- 橘色反向箭頭：大坑道 → 魯米那斯側出口。
- 標出入口、樓梯、方向名稱，不只畫一條沒有方向的線。

### 3. 大坑道 F2

- 青藍色主線：魯米側落點 → 米諾側樓梯。
- 橘色反向主線：米諾側落點 → 魯米側樓梯。
- 採集支線使用虛線，不與通行主線共用顏色。
- 爆岩與礦點使用不同圖示，並在圖例標示等級。

### 4. 米諾基亞側 F1

- 青藍色主線：大坑道落點 → `(85,93)` 出礦山。
- 橘色反向箭頭：米諾側入口 → 大坑道。
- 另畫金、鐵與達馬斯礦的短支線。

## 頁面上的快捷路線

地圖上方先放四張路線卡，讓使用者不用讀完全文：

1. **開米諾傳送**：魯米那斯村 → 三張固定圖 → 米諾基亞村。
2. **抓一級爆岩**：依玩家所在入口顯示較短方向，終點 `(105,34)`。
3. **挖 R8～R10 礦**：列出各礦點及是否混銅。
4. **挖 S11 弗羅爾達**：單獨一條支線，避免與舊版礦點混淆。

## 初心服實測清單

產圖前須實際走一次雙向路線，逐張記錄：

- 地圖正式名稱與地圖編號。
- 進圖座標、出圖座標及傳送後落點。
- 兩個方向是否走同一個換圖格。
- 所有已列礦點是否仍可採集、是否混礦。
- 奧利哈鋼正確座標是 `(80,138)` 或 `(40,138)`。
- 爆岩一級點是 `(105,34)` 或 `(105,35)`。
- `(169,15)` 是否位於同一張大坑道，以及前往該點有無初心新增阻擋或傳送條件。

實測紀錄至少保存「地圖編號、座標、畫面截圖」三項。確認後才將黃色問號改成正式標記。

## 實作順序

1. 用本站先前產生伊姆爾森林路線圖的 MapTool，輸出三張無標線的初心服地圖底圖。
2. 依實測座標計算雙向最短可走路徑，人工檢查樓梯與傳送格。
3. 產出三張洞內路線圖及一張庫魯克斯島區域圖，轉成壓縮 WebP。
4. 新增 `content/pages/地圖座標/庫魯克斯島/伊利斯礦山.md`，加入快捷路線、圖例、座標表與來源說明。
5. 在 `content/nav-order.json` 加入「庫魯克斯島」與「伊利斯礦山」。
6. 從挖掘頁、爆岩寵物頁、S 階生產採集頁連回此地圖頁。
7. 驗證桌面與手機顯示、站內連結及完整建置。
