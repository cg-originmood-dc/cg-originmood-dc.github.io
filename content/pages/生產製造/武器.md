八種武器製造技能，各自一頁。

| 製造技能 | 單手／雙手 |
| --- | --- |
| [劍](/生產製造/武器/劍) | 兩種都有 |
| [斧](/生產製造/武器/斧) | 兩種都有 |
| [槍](/生產製造/武器/槍) | 全部單手 |
| [弓](/生產製造/武器/弓) | 全部雙手 |
| [杖](/生產製造/武器/杖) | 幾乎都是單手，一把雙手 |
| [投擲武器](/生產製造/武器/投擲武器) | 全部雙手 |
| [小刀](/生產製造/武器/小刀) | 全部雙手 |
| [太刀](/生產製造/武器/太刀) | 全部雙手（永恆初心專屬） |

**雙手武器拿了就不能再拿[盾牌](/生產製造/防具/盾牌)。**

1～10 級整理自[蔚藍幻境](https://cg.skyey.tw/made/03/01.htm)（經典版魔力寶貝）；
11～12 級與整條太刀線為**永恆初心專屬**配方，各表以「初心專屬」欄標註。
