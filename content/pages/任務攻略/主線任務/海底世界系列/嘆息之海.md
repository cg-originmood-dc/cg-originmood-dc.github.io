<span class="hl-ref"><strong>嘆息之海</strong></span>

註.本次任務開啟，需要有<span class="hl-ref">無敵的勇者</span>稱號的角色

1.前往阿巴尼斯村外，找遇襲的村民(54.192)<span class="hl-key">進入戰鬥</span>

<span class="hl-mob"><strong>巨型鯊</strong></span> x3 血20000，2動 會普攻1000 超冰200 突襲2000 乾坤2000 單火1000 裂空800 潛龍殺1000 戰慄 超混

戰勝後會掉落一個 <span class="hl-ref"><strong>組織結晶</strong></span>(不能交易) <span class="hl-key"> (開打前請預留3格)</span>

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/1.png)

2.取得物品的人跟<strong>拉斐特</strong>(69.183)對話，了解要前往蒼月聖學院

3.到蒼月聖學院<strong>教師室</strong> 找生物學家<strong>萊妮博士</strong>(26.15)對話換取 <span class="hl-ref"><strong>黑潮水晶</strong></span>

4.使用<span class="hl-ref">基地卷軸</span> 或<span class="hl-ref">約定卷軸</span>傳至公主房間後
出門往左進傳石到海洋亂流找出口到費德奧亞海盆後 往西北走至<strong>傳送石</strong>(133.107)
進入<strong>費德奧亞環流</strong>500M在這邊找樓梯往下走至100M後看到傳石後
傳到<strong>費德奧亞海盆</strong>另一處，往西走到底會看到<strong>石碑</strong>(70.129)
進去後來到費德奧亞生物研究所(目前用途不明)，來到樓梯(102.86)進入<strong>伊斯頓海峽</strong>

或 持有<span class="hl-ref">無敵勇者</span>稱號(限單人) 至法蘭城西門外<strong>士兵弗洛克</strong>(349.179)直接傳送至 伊斯頓海峽

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/2.png)

5.在伊斯頓海峽找人魚少女<strong>塞壬娜</strong>(90.33)對話取得<span class="hl-ref"><strong>貝殼魔法袋</strong></span>
<span class="hl-ref">後續抓取少女寵物 啾啾需要的物品</span>

6.地圖為蘭艾2勳章的地圖，參考路線大致如上圖的橘色線建議直接驅魔吃滿快速離開，來到終點，黑龍旁邊的<strong>傳送石</strong>(72.178)傳至另一個地圖

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/3.png)

7.切換地圖後，往北走與<strong>泰坦龍蝦</strong>(45.35)對話<span class="hl-key">進入戰鬥</span>

<span class="hl-mob"><strong>泰坦龍蝦</strong></span> 血13000 1-2隻 測試屬性為火10風10 不怕法 會普攻 防禦 超石 聖盾 超火 潛龍殺

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/4.png)

8.戰勝後,切換地圖進入<strong>深海漩渦</strong> 到幽淵之徑

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/5.png)

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/6.png)

9.在幽淵之徑走 到樓梯(31.34)進入<strong>海王宮入口</strong> 與門(14.1)對話<span class="hl-key">進入戰鬥</span>

<span class="hl-mob"><strong>守墓靈</strong></span> 血15000 不吃咒、不怕法 會普攻 Ｔ隕900 超隕300 混波 超混 <span class="hl-key">魔封</span> 聖盾 連擊
 <span class="hl-mob"><strong>地獄骷髏</strong></span>x9 血3000 吃咒、吃法 會普攻 裂空斬 石化攻擊

10.戰勝後，切換地圖到<strong>海王宮殿</strong>，往下走進入迷宮中逐層搜索<strong>啾啾</strong>

![](/img/pages/任務攻略/主線任務/海底世界系列/嘆息之海/7.png)

11.找到<strong>啾啾</strong>與其對話，會被傳送回<strong>伊斯頓海峽</strong>(30.25位置)
<span class="hl-ref">若把啾啾交還給人魚少女塞壬娜可以換得 <strong>人魚珍珠</strong>，但無法後續任務　 </span>
<span class="hl-ref">(12等飾品 100-300血 100-250魔 不可交易)</span>

12.重複6-9步驟，回到<strong>海王宮殿</strong>找探險家<strong>伊利亞斯</strong>(50.56)用<span class="hl-ref">啾啾</span>交換 <span class="hl-ref">光噬菌</span>
 <span class="hl-ref">如果照NPC說的持有光噬菌找石碑會被傳回幽淵之徑 </span><span class="hl-key">(限定單人傳送 會收走光噬菌)</span>
 <span class="hl-ref">但隊伍內有人持有</span><span class="hl-key">深海龍王寵物在迷宮內找任意石碑可以直達<strong>海王殿</strong> </span>
迷宮有10層 迷宮不大 遇怪率一般 4H重置 血約 3600-3900 等級從100逐層增加到109
深海飛龍 飛行系 水10 裂空斬300 聖盾  寒冰龍骨 不死系 火10風10    混波200 聖盾

13.通過迷宮後，進到海王殿與<strong>深海龍王</strong>對話<span class="hl-key">進入戰鬥</span>
<span class="hl-key">需要同時有 </span><span class="hl-ref">黑潮水晶 與 光噬菌 才能開戰，開戰後物品會收走</span>

<span class="hl-mob"><strong>納葛洛斯</strong></span> 血25000，2動 乾坤2000 普攻600 潛龍殺 水祈禱 狀態攻擊 召喚琴瑟海妖x3
<span class="hl-mob"><strong>琴瑟海妖</strong> </span>x4 血5000，1動 吃咒 混波50 超風200 超冰200 超石 水祈禱 戰慄
<span class="hl-mob"><strong>近衛海妖</strong> </span>x4  血5000，1動 吃咒 普攻200 Ｔ隕400 裂空 潛龍殺500 聖盾 戰慄

14.戰勝會傳回召喚之間，隊伍中會獲得1個 <span class="hl-ref">未蝕寶箱</span> 任務結束
