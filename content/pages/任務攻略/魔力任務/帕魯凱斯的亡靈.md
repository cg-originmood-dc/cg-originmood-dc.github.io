<span class="hl-ref"><strong>帕魯凱斯的亡靈</strong></span>

從哥拉爾地下牢房回到過去，擊退帝國軍與巫術師阿夏芙，再深入伊姆爾森林迎戰帕魯凱斯。任務可重複進行，完成後可取得永久稱號<span class="hl-key">魔鬼剋星</span>。

## 任務資訊

| 項目 | 說明 |
| --- | --- |
| 起點 | 哥拉爾鎮白之宮殿地下牢房 |
| 建議等級 | 80 級以上 |
| 前置條件 | 戰鬥系完成「戰鬥系階級提昇Ⅲ」；生產系完成「生產系階級提昇Ⅲ」 |
| 時間限制 | 無 |
| 可否重解 | 可以 |
| 永久稱號 | 魔鬼剋星 |
| 主要獎勵 | 失魂的耳飾、帕魯凱斯之斧、阿爾卡迪亞古錢；過程中另有機會取得阿夏芙的耳飾 |

## 任務流程

### 1. 進入過去的哥拉爾

1. 到<span class="hl-key">哥拉爾鎮白之宮殿 (47,36)</span>，由左側樓梯進入地下牢房。
2. 與<span class="hl-ref">守衛利迪爾 (33,15)</span>交談，進入「地牢裡」。
3. 與<span class="hl-ref">徬徨的亡靈 (28,6)</span>交談，前往「過去的哥拉爾城地下牢」。
4. 與<span class="hl-ref">巫術師耶卡 (27,12)</span>交談，再到里雍的房間與<span class="hl-ref">勇者里雍 (10,7)</span>交談，進入過去的哥拉爾。

這一區會隨機遇到 60 級帝國兵，戰鬥後有機會掉落<span class="hl-key">阿爾卡迪亞古錢</span>。

| 道中敵人 | 等級／約略生命 |
| --- | --- |
| 男帝國兵 | Lv.60／約 2,300 |
| 女帝國兵 | Lv.60／約 2,400 |

### 2. 擊退帝國兵與阿夏芙

1. 到 (84,66) 一帶與<span class="hl-mob">帝國兵迪普拉</span>或<span class="hl-mob">少年兵凱拉</span>交談並進入戰鬥。
2. 勝利後會移動到 (84,76)，繼續前往 (84,84) 與<span class="hl-mob">魔術師阿夏芙</span>交談。
3. 擊敗阿夏芙後，有人可能取得<span class="hl-key">阿夏芙的耳飾</span>。隊伍會被送到營地，與<span class="hl-ref">帕魯凱斯</span>交談後返回現代地下牢房。

| 敵人 | 等級／約略生命 |
| --- | --- |
| 帝國兵迪普拉 | Lv.70／約 4,400 |
| 少年兵凱拉 | Lv.70／約 4,100 |
| 魔術師阿夏芙 | Lv.70／約 5,400 |

> 約略生命皆經永恆初心實際任務校正（by TonyQ），並採略保守的概估值。

#### 低等隊伍打法建議

若隊伍約 Lv.60～70、整體練度較低，可考慮收寵後排成 W 陣型，採「1 水 2 打」或「1 打 2 水」配置。戰鬥時盡量合擊或集中火力，一隻一隻擊倒，避免分散輸出。

#### 過去的哥拉爾路線圖

由過去的哥拉爾進圖位置 `(130,105)` 沿<span style="color:#0891b2"><strong>青藍色路線</strong></span>前往 `(84,65)`，與北側的帝國兵迪普拉或少年兵凱拉交談。第一戰勝利後會移動到 `(84,76)`，再沿<span style="color:#ea580c"><strong>橘色路線</strong></span>前往 `(84,83)`，與北側的魔術師阿夏芙交談。

![過去的哥拉爾兩段 Boss 路線圖](/img/pages/任務攻略/魔力任務/帕魯凱斯的亡靈/past-golar-46010.png)

<span class="hl-key">注意：</span>擊敗阿夏芙後，到魯米那斯長老領取後續物品之前，無法重新進入地下牢房。阿夏芙的耳飾可賣店 2,000G，也可在加納後方墓地使用，隨機換得 Q 零件或 O 零件。

### 3. 取得火把

到<span class="hl-key">魯米那斯長老之家 (94,43)</span>二樓，與<span class="hl-ref">長老普特 (12,14)</span>交談取得<span class="hl-key">火把</span>。在最終擊敗帕魯凱斯前，遺失火把可再次向長老領取。

### 4. 進入伊姆爾森林

1. 到<span class="hl-key">庫魯克斯島 (463,632)</span>踏上傳送石，進入「伊姆爾森林 入口」。
2. 身上持有火把時，調查<span class="hl-ref">警告牌 (28,13)</span>附近的入口。
3. 稱號會影響進入方式：
   - 持有「引導者」會先進入「盡頭之間」，與白龍交談。
   - 持有「閃耀者」會先進入「邊際之間」，與黑龍交談。
   - 沒有上述稱號則直接進入森林。

森林由固定地圖與隨機的「森之迷宮」交錯組成：

`入口 → 固定地圖一 → 森之迷宮 → 固定地圖二 → 森之迷宮 → 固定地圖三 → 森之迷宮 → 固定地圖四 → 森之迷宮 → 森之墓場`

「森之迷宮」每次地形可能不同，以下路線圖只適用於五張固定森林地圖與森之墓場。

## 回報與獎勵

回到魯米那斯長老之家二樓，向<span class="hl-ref">長老普特 (12,14)</span>回報，可取得<span class="hl-key">失魂的耳飾</span>與永久稱號<span class="hl-key">魔鬼剋星</span>。

| 道具 | 能力 |
| --- | --- |
| 失魂的耳飾 | Lv.5 耳飾，耐久約 100～150；攻擊 -3～+10、防禦 -2～+10、敏捷 -3～+10 |
| 帕魯凱斯之斧 | Lv.8 單手斧，耐久 300、攻擊 +250、必殺 +18，並會改變乾坤一擲的耗魔 |
