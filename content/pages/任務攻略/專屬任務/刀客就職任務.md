## <span class="hl-ref">刀客就職任務</span>

# 刀客就職任務:

# 條件

# 持有精靈族使者稱號

# 職業為劍術大師、戰斧大師、鐵血騎士、遊俠、重戰士、格鬥王、陰、大魔導師、大主教、巫王、咒術大師以上其中一種

# 1.前往白砂村找鷹取(71,57)接任務

# 2.在布倫尼亞村民宅(57.53)與巴蒂安(8,7)對話拿取"給女兒的信" ，在偏僻的洞窟中尋找隨機出現的希兒，交談後繳出"通靈珠"並取得"傳送石符咒"

# 3.從海澤蘭冰原(88,11)進入偏僻的洞窟

# 4.持有"傳送石符咒"與迷宮內的紅水晶對話，若是正確的水晶會抵達隱密的據點，錯誤的收回"傳送石符咒"並傳出迷宮

# ☆持有咒殺型山吹與任一紅水晶對話則不須先取得"傳送石咒符"即可抵達隱密的據點

# 5.在隱密的據點與海格(12,13)對話，每人繳出10個"精靈王契約"抵達濕地洞窟入口

# ☆"精靈王契約"在精靈城競技場取得

# 6.與費昂(10,4)對話取得"費昂的委託"

# 7.在濕地洞窟進入(or對話)黃色傳送石，若為正確即抵達濕地洞窟底層

# ☆持有深淵石像魔王即可進入任一黃色傳送石抵達

# 8.與石碑(23,17)對話進入二連戰，第一戰為迷你龍以及4隻迷你石像鬼，難度低，第二戰為龍魂以及4隻深淵石像魔王，難度高

# 9.戰勝後與石碑(23,17)對話取得"龍精石"

# 10.回去白沙村找鷹取(71,57)，進入民宅與費昂(15,9)對話，繳出"龍精石"以及"費昂的委託"，獲得"費昂的承諾"

# 11.到精靈城銀行(75,77)與阿爾文(7,3)對話輸入"大師傅"，得知破風刃需要"黯星物質"以及30"炎能魔粉"，獲得"阿爾文的需求"

# ☆"黯星物質"在星辰塔取得，"炎能魔粉"在火山密道取得

# 12.繳出"黯星物質"、30"炎能魔粉"以及"阿爾文的需求"獲得"破風刃"

# 13.回去白沙村找鷹取(71,57)，進入民宅與費昂(15,9)對話，繳出"費昂的承諾"以及"破風刃"獲得"刀客推薦信"

# 14.持有"刀客推薦信"前往精靈城刀客公會(106,120)找無心(17,4)就職刀客
