人物技能。官方說明是「造成基礎傷害 + 精神倍率」；倍率每級 +2%，LV1 為 62%、LV12 為 84%。下面是依高精神實測整理的工作公式，用來把那句話算成畫面數字。

學習位置見 [混沌的宿命](/任務攻略/主線任務/混沌雙子系列/混沌的宿命)。技能本身的耗魔與文案見 [精神衝擊波](/skill/shared/精神衝擊波)。

## 工作公式

M＝精神，L＝技能等級，D＝顯示防禦。h(L) 查本頁表格。

```
A = ⌊ ((60 + 2L) × M + h(L)) / 100 ⌋
X = A² / ( ⌊A / 3⌋ + max(D, 1) )
畫面傷害 = ⌊ r × X ⌋
```

- 精神係數與官方相同：`(60 + 2L) / 100`，LV12 即 84%。
- h(L) 是該等級的基礎項（官方所稱「基礎傷害」的工作常數），目前用查表，沒有已證實的跨等級閉式。
- 表上的 0 防與 1 防，可見傷害相同，公式一律用 `max(D, 1)`。
- r 約 0.90～1.10；倍率 1.00 時畫面為 `⌊X⌋`。
- 分母把攻擊收到 3 的倍數：分子每次 +1，分母一次跳 3。

LV12 試算（試算表，A1＝精神、B1＝防禦）：

```
=INT((84*A1+15335)/100)^2/(INT(INT((84*A1+15335)/100)/3)+MAX(B1,1))
```

其他等級把 `84` 換成該級精神係數、`15335` 換成表上的 h 工作值。

## 驗算例子

精神 348、LV12、防禦 0（代入時當 1）：

```
A = ⌊(84 × 348 + 15335) / 100⌋ = 445
X = 445² / (⌊445 / 3⌋ + 1) = 198025 / 149 ≈ 1329.03
畫面中心 = 1329
```

精神 350、LV12、防禦 0：A＝447、畫面中心＝1332。

## 適用與未定

<span class="hl-key">高精神（約 348 以上）</span>的 0 防與已有防禦曲線，對得上上式。  
<span class="hl-key">低精神</span>（例如 330、310、156）實測低於本式，門檻與門檻下罰則尚未鎖定，請勿用低精神去改高精神主式。

h 工作值落在表列可行區間內即可得到相同整數 A；表上數字是區間代表值，不是官方公布的唯一常數。
