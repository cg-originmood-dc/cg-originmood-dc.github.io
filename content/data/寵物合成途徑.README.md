# 寵物合成途徑資料定義

這組資料是合成圖的穩定資料層，不在網站建置時重新解析公告公式。

## 檔案

- `寵物合成途徑.csv`：一列一條配方，保留公告、NPC、來源及完整公式原文。
- `寵物合成途徑-材料.csv`：一列一項投入材料，以 `配方ID` 關聯主表。
- `寵物合成途徑-產物.csv`：一列一項產物，以 `配方ID` 關聯主表。

`配方ID` 是穩定關聯鍵。新增配方時配置新的 ID；不要因排序或插入資料而重編既有 ID。

## 主表規則欄位

規則只描述公式已明確表達的形狀，不推測遊戲語意：

- `材料規則`
  - `同列共同投入`：材料明細中的項目屬於同一條配方。
  - `無材料`：來源沒有列出投入項目。
- `產物規則`
  - `單一產物`
  - `多產物機率分支`
  - `多產物（關係未載明）`
- `規則備註`：只填公告或人工確認的明確規則；不要自動寫入「取得／重抽／轉換」。

## 材料與產物

- `種類`：`寵物`、`道具`、`金幣`。
- `名稱`：結構化名稱；來源寫法仍保留在 `原文`。
- `名稱狀態`
  - `已對應寵物表`
  - `已對應道具庫`
  - `已定義`（目前用於金幣）
  - `來源原文`（角色已明確，但本站名稱表尚無可安全對應的名稱）
- `數量`：只填來源明載的數字；空白不自動猜成 1。
- `機率`：只存在產物表，保留 `%`。

寵物等級條件分為：

- `任意`：來源寫「任意等級」。
- `指定`：來源只寫 `LvN`，不擅自解讀為最低等級。
- `至少`：來源明寫 `LvN以上`。
- `原文待確認`：來源有 `Lv` 字樣但沒有數字。

`條件備註` 保存不屬於等級的限制，例如「屬性：水10」。

## 循環群組

循環不另外人工標記。網站只從材料表與產物表的明確寵物連線建立有向圖：

`材料寵物 → 產物寵物`

若一組至少兩隻寵物在有向圖中互相可達，才列為循環群組。這只代表配方關係上的互相可達，不代表「重抽」、「進化」或其他未經資料確認的規則。
