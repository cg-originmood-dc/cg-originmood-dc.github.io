# 寵物詳情補充資料

此檔供之後 agent 收集後寫入，結構為：

```json

    "sealable": false,
    "cardLevel": "金卡 5 級",
    "skillNotes": {
      "超強昏睡魔法LV10": "使敵方全體陷入昏睡狀態"
    },
    "growth": [
      {
        "level": "1 等",
        "hp": "135",
        "mp": "185",
        "atk": "36",
        "def": "36",
        "agi": "65",
        "spi": "105",
        "rec": "100"
      }
    ],
    "questNote": "攜帶效益說明…",
    "obtainMethods": [
      {
        "type": "capture",
        "map": "埃瑞亞島",
        "coords": "650.426",
        "note": "附近刷新",
        "link": "/任務攻略/…"
      }
    ],
    "fusionTree": {
      "type": "pet",
      "name": "目標寵物",
      "image": "/img/專屬寵物/xxx.gif",
      "target": true,
      "npc": "NPC 名稱 @ 地圖 (x.y)",

        }
      ]

}
```

- `type`（合成樹節點）：`pet` | `item` | `gold` | `material`
- 合成樹為「樹尖在上、向下解構」；`children` 可多層巢狀
- **入手資料分工**：
  - CSV `專屬寵物.csv` 的 **`入手方法`**（短述，可 Markdown 連結）、**`入手類型`**（捕捉／合成／任務／活動／兌換／未知）— 列表與詳情主顯示
  - 本檔 **`obtainMethods`** — 多筆、結構化細項（地圖、座標、說明、連結）
  - **`任務用途`** / `questNote` 是「帶寵任務效益」，不是入手方式
  - `obtainMethods[].type`：`capture` | `fusion` | `quest` | `event` | `exchange` | `other`（或直接寫中文）
- **風之使徒** 已內建於程式（對齊 `pet_page_template.html`，使用者確認正確），不要用此檔覆蓋
