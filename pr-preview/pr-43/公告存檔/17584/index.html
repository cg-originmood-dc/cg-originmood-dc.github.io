《魔力寶貝》25週年誕生慶典 正式開啟！

2026-07-29 公告 17584 官網原文 ↗

由日本 SQUARE ENIX 開發的經典日系角色扮演線上遊戲《魔力寶貝》，今年迎來第 25 個年頭！
二十五年，不只是一段時間，而是一座紀念碑。
它刻著勇者們在法蘭大陸踏過的每一個腳印、每一次戰鬥、每一場分別與重逢。從初踏里謝里雅堡的青澀，到獨自面對命運之門的堅定，冒險從未止步。
《魔力寶貝》陪伴大家走過無數春夏秋冬，也因為你們的存在，世界才能如此閃耀不滅。
如今，我們迎來第25個誕生年。在這個意義非凡的時刻，我們懷著滿滿感謝，向每一位勇者致上最深的敬意與祝福，也正式宣布——《魔力寶貝》25週年誕生慶典隆重登場！
這不只是一場慶典，更是一封獻給所有勇者的情書。
豐富的活動、限定的寶箱與各種經典重現，再次點燃你的魔力記憶——讓我們重回那段名為冒險的青春。

活動一：「寵物島慶典」
活動時間：2026年7月30日12:00 ~ 2026年8月27日12:00

         里謝里雅堡門前5只可愛的老鼠前來為25週年送上賀禮，他們會引領我們前往寵物的世外桃源：大地鼠寵物島、火焰鼠寵物島、惡夢鼠寵物島、寶石鼠寵物島以及水藍鼠寵物島這5個島嶼。

         這裡有大批寵物寶寶等著我們封印，其中還有大量珍稀的寵物寶寶。勇者們在25週年慶典活動中可以通過完成寵物島島主的每日任務獲得25週年紀念幣。

         更值得注意的是！在這個島嶼上有眾多原住民等待著勇者的幫助，幫助它們完成任務即可獲得「週年紀念幣兌換」以及珍貴的「週年鼠王勛章」！它們更有機會兌換平時無法獲得的珍貴道具！千萬不可錯過！
