精靈之墟練級點前置攻略

精靈之墟練級點前置攻略

作者：羁绊Nexus

【前言】

本攻略需要先完成前一份攻略【冰原練級點前置攻略】中的任務內容，如未完成則無法開展此攻略

中的內容。本攻略將完結【傳說之劍】系列攻略的內容，並最終獲得完全免費寵物【守護天使】。

本攻略符號注解。【】表示為該步驟中王戰屬性、王戰打法建議；◇表示該步驟中需要注意的事項。在使用本攻略時，建議在開展當前步驟之前，將該步驟對應的【】及◇的內容提前閱讀，以便做好充分的攻略準備。

◇該寵物為攻敏分佈寵物，與目前主流練級所使用的血攻寵物分佈均不相同，且初始技能格僅為8格，可以說是讓平民玩家擁有氣功彈練功、諸刃解任務的寶貴寵物，但由於其功敏的BP分佈，不要有過大期待。

◇本攻略中，如對BOSS、分身或小弟標誌抗咒、抗法則表示該單位不吃咒術魔法或攻擊、不吃魔法攻擊（或傷害較低），如未標誌則表示該BOSS、分身或小弟不存在此抗性。

1.通過貝克岩洞前往布倫尼亞村，與烈焰精靈使（71.71）對話，每人交出【通靈珠*10】，獲得【火的意志】。

◇通靈珠在貝克岩洞打貓臉女神掉落，通靈珠為可交易物品，此步驟可以通過從玩家手中收購省略

【第1步狩獵女神任務流程】

2.通過海澤蘭洞窟前往娜迦村，進入村長家（88.93），與村長（9.6）對話，交出【火之意志】，獲得【落神峰通行證】。

3.從娜迦村北門出發，在海澤蘭冰原與豪傑（65.30）對話進入戰鬥。

【BOSS為豪傑單人，抗咒，約6000血，2動，會聖盾、單冰】

4.打敗豪傑後進入落神峰，於迷宮中尋找隨機出現的撒旦（裏雍形象），對話進入戰鬥，戰鬥勝利後獲得【羽毛】，每人均需獲得。

◇迷宮約15層，怪物約1500血，55級起步，每層加1級

◇羽毛為可交易物品，此步驟可以通過從玩家手中收購省略

【BOSS為撒旦，2動，屬性偏地，抗咒，約7000血，會召喚】

【BOSS打法建議：戰鬥前控制高敏（如控魔、控血、使用高敏寵物等），使用魔寵一回合集火消滅】

5.於落神峰頂與天空元素使（35.30）對話，交出【羽毛】，獲得【花園共鳴符】、【天空傳羽】。

◇於風精（29.29）可學習聖騎之譽，只有本步驟內可學習，如進度超過本步驟，則不允許學習

6.從塔布基爾村南門出發進入萊比聖洞窟（695.520），於萊比聖洞窟8F，與石碑（44.5）對話，進入洛亞的花園。與牙牙（39.20）對話進入戰鬥。

◇戰鬥前請每人預留3格背包空位

【BOSS為三連戰。第一場為魔兵10名，1動，屬性地，約3000血，會吸血魔法、強法、聖盾、超咒、乾坤。第二場為魔兵10名，1動，屬性火，其他屬性與第一場相似。第三場為裘貝和巨魔4名，屬性地，均為2動，裘貝，約7000血，會乾坤、聖盾；巨魔，約10000血，會吸血魔法、混亂攻擊、超咒、聖盾、強法】

7.戰鬥後全隊會掉落5個【不明？】，需鑒定，鑒定後為【刀刃碎片】。雙擊【天空傳羽】飛往落神峰頂。與天空元素使（36.31）對話後，與或撒旦（37.36）對話進入戰鬥。

【BOSS為二連戰。第一場為哈迪爾和風使，均為2動，哈爾迪，抗咒、抗法，必殺反擊較高，約1萬血，會氣功彈；天空元素使，約1萬血，使用單風攻擊哈爾迪，在哈爾迪死亡或回合維持時間較長會自爆。第二場為撒旦和撒旦分身*9，屬性偏地，撒旦2動，抗咒、抗法，約9000血，會連擊、突襲之舞、潛龍殺、超咒術；分身1動，約4000血，會吸血攻擊、乾坤、混亂攻擊、聖盾、超咒】

【BOSS打法建議：第一場使用群攻同時削弱哈爾迪和風使血量即可，注意保留魔量。第二場使用超毒、群攻、群法，清理分身後再集火撒旦本體】

8.解散隊伍後與撒旦（36.31）對話，交出【刀刃碎片】和【落神峰通行證】，獲得【風之意志】。

【第2步至第8步為洛亞花園任務流程】

9.通過蒼峰山道前往白砂村，進入村長家（68.40），與村長（17.10）對話交出【風之意志】，獲得【村長的推薦信】。於商店（91.72）與維伊斯坦（12.6）購買多把【切水劍】。

◇如持有寵物【神聖巨龍】的玩家，可不購買，具體步驟見下

10.從白砂村東門出發進入蒼峰山道（496.770），與蒼峰山守衛（12.7）對話，通過柵欄。與溫格雷（36.4）對話後，進入蒼峰山道（36.25）。

◇迷宮約15層，怪物等級80，怪物約2000血，會強法、戰慄

11.於迷宮中尋找隨機出現的狐狸幻影（存在多個，可能為真或假），交出【切水劍】後進入判定，如為真則傳送至蒼峰山埡口，如為假則傳出迷宮。

◇如隊伍中有任意隊員持有寵物【神聖巨龍】，可無視真假，與任意狐狸對話後傳送整隊至蒼峰山埡口

◇此迷宮無論是否持有寵物【神聖巨龍】，均僅可通過與狐狸幻影互動的方式傳至蒼峰山埡口，即使玩家爬到15F的黃色傳送石，仍然會被傳送回洞口

12.於蒼峰山埡口與九尾狐（28.28）對話進入戰鬥。

◇該BOSS戰為九場連續戰鬥，為魔力寶貝官方伺服器歷史上主線中最長的連續戰鬥，請準備好純水水晶，帶好護符、血瓶、補血寵物，並做好長期戰鬥的準備，此戰中寵物起到決定性作用，請帶你最好的血攻分佈的水屬寵物，如有條件配置【神聖巨龍】或其他超補寵物，建議配置2只或以上，寵物可以學習毒攻、石化攻擊等咒術攻擊，並學好各種抗性（個人建議在預算充足的前提下，使用寵擴擴張寵物技能格，學滿六種抗性）

◇BOSS戰難點在於第四場（超酒醉）與第七場（混波、裂空斬），所以前三場戰鬥建議儘量保留魔量，如果掉血由寵物負責超補、人物負責丟水；第七場應起手單石化，同時寵物使用石化攻擊。所以本場9連戰最好的配置是準備兩只【神聖巨龍】（第五場後魔量不佳更換另一只）和兩隊血攻寵物（第七場前更換上場，保證有魔可以使用石化攻擊控場）

【第一場狐狸9只，均2動，抗法，血量約7000，會超毒、偷錢，超火、超風、聖盾、明鏡，建議使用中毒後合擊逐個消滅；

第二場狐狸8只，均2動，抗法，血量約7000，會超睡、經驗竊取（無實際效果）、超火、超風、聖盾、明鏡，戰鬥思路與第一場一致；

第三場狐狸7只，均2動，抗法，血量約7000，會超石、魔封、超火、超風、聖盾、明鏡，戰鬥思路與第一場一致；

第四場狐狸6只，均2動，抗法，血量約7000，會超酒醉、暗殺、超火、超風、聖盾、明鏡，由於該場次敵方會使用酒醉，應儘快消滅、控制或者潔淨，在我方單位不存在被酒醉單位的前提下，狐狸會持續酒醉我方，可利用此機制；

第五場狐狸5只，均2動，抗法，血量約7000，會超混、超恢（超恢對我方使用）、超火、超風、聖盾、明鏡，由於本場敵方會幫助我行補血，應在敵人的配合下保持血線健康；

第六場狐狸4只，均2動，抗法，血量約6000，會超遺忘、氣功彈（氣功彈固定傷害為1點），超火、超風、聖盾、明鏡，戰鬥思路與第一場一致，戰鬥結束前可以調整為W站位以盡可能規避混波影響；

第七場狐狸3只，均2動，抗法，血量約7000，會混波、裂空斬、超火、超風、聖盾、明鏡，該場由於敵人會使用混波、裂空等強力輸出技能，應儘快控場；

第八場狐狸2只，均2動，抗法，血量約7000，會超遺忘、氣功彈（氣功彈固定傷害為1點）、超火、超風、聖盾、明鏡，手段與前面一致；

第九場狐狸1只，均2動，血量約7000，會反擊、單火、單體即死、召喚。召喚物為小狐狸（一次4只），會單體即死、召喚。由於敵人會無限召喚，且大狐狸不抗咒，可起手使用石化魔法定住大狐狸，如順利可慢慢擊殺，如未成功，則應該以最大輸出儘快消滅大狐狸】

13.解散隊伍後與魔劍（31.29）對話交出【月刺】，獲得【月神之淚】並傳回蒼峰山道。與溫格雷（12.8）對話，交出【月神之淚】，獲得【溫格雷的答覆】。

14.返回白砂村的村長家與村長（17.10）對話，交出【村長的推薦信】、【溫格雷的答覆】，獲得【解印符】。

【第9步至第14步為鎮魂之歌任務流程】

15.前往赫蓮娜島，與被封印的結界之樹（244.211）對話，選【是】進入巨樹迷宮。與艾爾迪隆（10.38）對話，選【否】進入戰鬥。

◇該位置有三種前往方法，①完成天空之島主線任務，獲得前往赫蓮娜島的資格，然後傳送至艾爾瑪城；②使用艾爾瑪城傳送卷（可選擇使用定居卷開通傳送許可權）；③使用海拉爾村傳送卷（由於暫時未開放傳送NPC，故無法開通傳送許可權）

【BOSS為艾爾迪隆和貝克斯（貝克斯數量為1至5只隨機）屬性偏地，艾爾迪隆，2動，抗咒、抗法，約1萬血，會裂空斬、乾坤、魔封、聖盾；貝克斯，2動，約8000血，會裂空斬、聖盾】

【BOSS打法建議：由於小怪數量為隨機，如隊伍整體實力較弱，且小怪數量較多，可考慮逃跑後重新戰鬥】

◇請看本攻略的玩家放心，您已經打過九連戰狐狸這場最噁心、最困難的王戰了，剩餘王戰對你來說都很簡單，只要屬性克制關係應用正確即可輕鬆獲勝

16.進入巨樹迷宮，該迷宮為固定地圖。依次前往綠色傳送石（37.8），前往樓梯（16.17），前往藍色傳送石（8.23）進入極地之海。

◇巨樹迷宮怪約71等，1500血。

◇極地之海怪物91至100級，約2500血，戰鬥難度較高。怪物會超火、聖盾、戰慄、石化攻擊。

17.於迷宮中尋找隨機出現的石碑（存在多個，可能為真或假），對話進入判定，如為真則傳送至終極之地，如為假則傳出迷宮。

◇如隊伍中有任意隊員持有寵物【暗黑魔龍】，可無視真假，與任意石碑對話後傳送整隊至終極之地。

18.與終極之地的溫格雷（18.23）對話，與海洋元素使（14.155）對話，進入戰鬥。

◇終極之地怪物約101至110級，固定2動，會強法、強力即死，建議收寵逃跑

【BOSS為哈爾迪和海洋元素使，屬性偏地水，哈爾迪，2動，抗咒、抗法，約9000血，首回合固定召喚4只分身，會超石化、石化攻擊、崩擊、連擊、氣功彈、潛龍殺（血量較低時追加）。哈爾迪分身，2動，抗咒、抗法，約9000血，技能與本尊一致。海洋元素使，2動，抗咒、抗法，約3000血，會使用氣功彈或連擊攻擊哈爾迪，在哈爾迪本尊或任意分身死亡或達到一定回合自爆】

【BOSS打法建議：建議使用群攻（裂空斬最優，既可以有效打擊哈爾迪，又可以避免誤傷水使），整體降低哈爾迪本尊及分身血量，待出現潛龍殺（血量較低）時一口氣整體解決掉。但此方法對於隊伍整體回復要求較高，故也可以選擇逐個擊破】

19.解散隊伍後與海洋元素使（59.130）對話，交出【解印符】，獲得【時空元素盤】*2、【神血密封瓶（空）】。

◇如月之勇者任務中，兩次機會均沒有擊敗BOSS，則需要找其他玩家購買可交易的時空元素盤

【第15步至第19步為地獄之眼任務流程】

20.雙擊時空元素盤後直接飛往聖壇，與聖劍（40.12）對話進入戰鬥。

◇聖壇遇敵率較高，怪物100至103級，約2000血，會超火、裂空斬、聖盾、戰慄

【BOSS為露米婭和聖劍，聖劍屬性為地水、露米婭及分身屬性為水。露米婭，2動，抗咒、抗法，約1.8萬血，首回合固定召喚4只分身，會超石化、連擊、超冰、單冰、護衛（聖劍）。露米婭分身，2動，抗咒、抗法，約1.8萬血，技能與本尊一致。聖劍，2動，抗咒、抗法，約1萬血，會海洋祈禱、強補、明鏡、攻反】

【BOSS打法建議：建議使用地屬性寵物，開場使用地祈禱。集火優先擊敗聖劍。露米婭敏捷較高，會追擊血量較少的單位，注意保護。露米婭分身有一定幾率護衛本體，可以利用這一機制優先消滅部分分身並降低戰鬥損耗，考慮到如果分身團滅的話有概率繼續召喚，可以留一只分身時消滅本體再消滅最後的分身】

21.解散隊伍後與守護天使（40.9）對話，交出【神血密封瓶（空）】，獲得【得到神血密封瓶（滿）】，並傳送至召喚之間。

23.前往法蘭城謁見之間，與國王（7.4）對話，交出【傳說中的聖劍】，獲得【守護天使之卵】。

【第20步至第23步為月之勇者眼任務流程】

26.走到空間魔法陣（20.16），選【是】進入精靈之墟。與空之亡靈（142.102）對話，進入牢籠結界入口。

◇精靈之墟怪物為番茄公主、棉球，等級30-34級。

27.從牢籠結界入口22.19進入空之結界1層。

◇該迷宮共15層，刷新時間為4小時，頂層（牢籠結界）可以躲避刷新。迷宮中怪物等級為93至101層，怪物為火龍蜥和火精，怪物血量約1800至2000血，使用純水水晶兩個超冰可以穩定秒殺，怪物會使用戰慄。本迷宮會隨機遇到小王（可偷襲），怪物為見習惡魔，血量2500-3000血，可以用吃法吃咒，打贏小王全隊隨機掉落0至5個月光之露（不可交易）。

◇迷宮中有多個上升樓梯，但只有一個為真樓梯。迷宮中存在多個空之碑，如果為真可直接登頂，如果未假會被傳出迷宮，如玩家持有一只惡魔女帝，可無視真假碑，將全隊傳送至樓頂（牢籠結界）。每個人交出10個月光之露後可以進入永夜之墟。

◇月光之露用途共有兩個。一是在精靈之墟與尼修斯（90.93）對話，交出20個月光之露，獲得道具【賞金袋】，打開後隨機獲得道具獎勵。二是作為進入永夜之墟的門票，進入永夜之墟後，可以選擇與女帝卡妮露戰鬥（戰鬥難度極高，由於不屬於本次練級點前置的必須步驟，故不列示），戰鬥後再交出10個月光之露後可以獲得【聖杯】，打開後隨機獲得道具獎勵，如果為了獲得聖杯，每位玩家至需要準備20個月光之露。也就是說，無論你選擇【賞金袋】或者【聖杯】作為獎勵，每位角色都至少需要準備20個月光之露。另外，可以交出10個月光之露，獲得【惡魔之戒】，佩戴可獲得稱號【惡魔】。
