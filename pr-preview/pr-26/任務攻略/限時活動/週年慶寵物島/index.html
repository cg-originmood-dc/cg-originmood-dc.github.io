週年慶寵物島

寵物島之旅

里謝里雅堡門前5隻可愛的老鼠前來，他們會引領我們前往世外桃源：寵物島。這裡有大批寵物寶寶等著我們封印，其中還有大量珍稀的寵物寶寶。勇者們在週年慶典活動中可以通過完成寵物島島主的每日任務獲得紀念幣。完成任務即可獲得「紀念幣兌換」以及珍貴的「鼠王勛章」！收集「鼠王勛章」更有機會兌換平時無法獲得的珍貴道具！千萬不可錯過！

每日入場:1次 / 入場費:5000 (其他須透過祕寶取得入場卷)

里謝里雅堡門前有5隻老鼠傳送師，可前往五座寵物島；各島的階級與角色等級條件詳列於下方島主資料。

戰鬥中會隨機出現1等寶寶(純陣行)，每交一次寶寶會獲得20個紀念幣(不可交易)及1個鼠王勛章(不可交易)，湊齊一定的數量可以換得獎品 (寶寶不能重複交；下表沒有座標的寵物會標示「一級寵無法交付兌換」) 戰鬥中會隨機掉落黑森林蛋糕(不可交易)，各島島主皆可收取5個並兌換紀念幣(每日限換1次)。

⚠ 特別危險：會使用「群體即死」或「活殺氣功彈」的寵物，表格會將整隻寵物標成紅色。

戰慄襲心：會吸魔，本身不列為特別危險，但可能造成補魔等財產損失，技能以藍色標示。
