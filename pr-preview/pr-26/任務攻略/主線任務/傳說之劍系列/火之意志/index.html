火之意志

火之意志 駐1.未解主線任務的玩家，可透過精靈城卷軸到達 或使用精靈城傳送許可證先行記點 駐2.持有地的意志的玩家才可繼續完成主線任務

1.從哥拉爾村和奧德希爾德對話後傳到塔布基爾村後，從南門出去到萊比聖洞窟(695.520)，迷宮路線(從10樓開始走)，怪物等級約55-60，血量不多傷害不高，會低機率掉落R10精靈靴和R10灰鑽石，皆為未鑑定物品)，走出洞窟後來到諾爾特島

2.往西南走一點進到精靈城，在到城中和努維奇(65,76)對話記點(傳送費5000G)

3.來到中央城堡的宮殿大廳找精靈女皇(9,3)對話後繳出地的意志，拿到女皇的考驗

4.再來到前廳找第五軍團長雷文(80,28)對話，得知須要到城外打雪獅的魔核

5.城外小怪等級約50-60，血1200，傷害不高，會隨機遇到雪獅，血6000，1動，吃咒、不吃法，普攻500、乾坤1000、單冰1500，快死時會逃跑，打贏後隊伍隨機一人拿到不明? 鑑定後為雪獅的魔核，每人都有後再回城找雷文對話繳出魔核後拿到雷文的推薦信

6.然後來到競技場中找麥可因(24,15)對話後進入試煉 而旁邊的櫃台NPC可以花10000G挑戰競技場NPC(每日可進1次，5種難度自選) 打贏後依難度獲得1~50精靈族靈魂碎片，200個碎片可換1個精靈王契約

7.試煉有三階段，第一階段在迷宮攻擊殺石頭金剛取得真視的鑰匙，然後在迷宮內尋找真視之石，迷宮10分鐘重置(無法回頭出迷宮)，內有多顆真視之石，若是錯的則鑰匙會消耗一把且該角色傳送至競技場，若是正確則該角色進到第二階段

巨石金剛，血2500、吃咒、不吃法，一次出現1-9隻，可偷襲，普攻200、諸刃400、超隕300，鑰匙非必定掉落且不可交易，建議可以多打幾把後再做嘗試

8.到第二階段後，此部分為是非題，單人對話，與真視之引對話，依序選"是否否是否否否否否"，全數答完之後傳到第三階段 (題目答案都固定，不要不小心選錯都OK)

9.來到第三階段，準備打BOSS，建議把血量拉高至2500，裝地水水晶

＊挑戰聖龍失敗後，若已經登出的話得先把鑰匙丟掉再從頭開始

聖龍 血10000，2動，不吃咒、不吃法，普攻800、單火1500、強冰800、潛龍殺2500，明鏡1500 (偶數回合二動必定使用潛龍殺，目標隨機)

翼龍 血5000，1動，吃咒、吃法，普攻400、強冰800、會混亂攻擊、超咒、聖盾

打法首先全放有吸魔的體攻寵，開場寵物全吸魔聖龍，人物放多體輸出或超咒控場，吸乾聖龍後再逐一殺掉翼龍，剩BOSS後在普攻合擊就差不多結束了

10.打贏之後解散隊伍，和聖龍對話後繳出雷文推薦信和真視鑰匙，傳出迷宮至競技場並拿到神龍的認可，再去城堡找精靈女皇

11.和精靈女皇對話後，繳出女皇的考驗和神龍的認可，拿到永久稱號精靈族使者

12.出北門，往西走到貝克岩洞(313.723)第1層(小怪會掉落R11通靈珠和R10黑曜石，皆為未鑑定物品)，怪物等級55-60，血量不多傷害不高，之後來到布倫尼亞村，此時可先到村長家記點

13.來到布倫尼亞村找到烈焰元素使(72,71)，得知每人需要通靈珠10顆

＊通靈珠可至貝克岩洞打貓臉女神掉落

14.收集完10顆通靈珠後和烈焰元素使對話，繳出通靈珠後得到火的意志
